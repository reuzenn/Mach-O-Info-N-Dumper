# Mach-O-Info-N-Dumper
A lightweight C++ Mach-O binary analyzer and dumper for ARM64 and ARM64e, providing Mach-O header information, load commands, segments, sections, Objective-C classes and methods, and basic C++ vtable analysis for reverse engineering &amp; basic information.
Compiled using G++ 
to compile via G++: g++ macho.cpp -o MachOExplorer.exe -mwindows -lcomdlg32 -lgdi32 -luser32
